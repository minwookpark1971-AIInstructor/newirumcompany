# 이룸아카데미 사이트 편집 MCP 사용 매뉴얼

채팅으로 말하듯 시키면 사이트의 문구·프로그램·신청/문의를 바꿀 수 있습니다.
도구 이름을 알 필요가 없고, 아래 "이렇게 말하세요" 예시를 그대로 쓰면 됩니다.

---

## 1. 시작하기

### 1-1. 연결 정보

| 항목 | 값 |
|---|---|
| 커넥터 URL | `https://tdayexcmksjfryhthyfz.supabase.co/functions/v1/site-mcp` |
| 로그인 | Google 계정 (관리자로 등록된 계정만) |
| 승인 화면 | `https://www.irumcompany.co.kr/html/oauth-consent.html` |

### 1-2. 연결 방법 (최초 1회)

1. Claude 웹(또는 데스크톱) → 설정 → 커넥터 → 커스텀 커넥터 추가
2. 위 커넥터 URL만 입력 (Client ID/Secret 칸은 비워 둠)
3. 열린 승인 화면에서 **Google로 로그인** → 관리자 계정 선택
4. 앱 이름이 `claude-site-editor`인지 확인하고 **승인**

### 1-3. 연결 확인

채팅에서 이렇게 말합니다.

> 사이트 편집 현황 보여줘

콘텐츠 키, 프로그램 수, 미처리 신청·문의 수가 나오면 정상입니다.

### 1-4. 연결이 안 될 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 이메일/비밀번호 입력란이 나옴 | 구버전 화면 또는 캐시 | Ctrl+F5 새로고침 후 새로 연결 |
| "관리자로 등록되지 않은 계정입니다" | 로그인한 Google 계정이 `admins`에 없음 | 등록된 계정으로 다시 로그인 |
| "허용되지 않은 앱입니다" | 승인 요청의 콜백 주소가 Claude 커넥터가 아님 | 직접 연결한 것이 아니면 닫기 |
| "잘못된 요청입니다 (authorization_id 없음)" | 승인 화면을 주소창으로 직접 연 경우 | 커넥터에서 연결을 새로 시작 |
| 연결은 됐는데 도구 호출이 실패 | 로그인 만료 | 커넥터를 해제 후 다시 연결 |

## 2. 할 수 있는 일

### 2-1. 메인 페이지 문구 (irumcompany.co.kr)

메인은 위에서 아래로 아래 구역으로 구성되며, 각 구역이 DB 키 하나에 대응합니다.

| 구역 | 키 | 바꿀 수 있는 것 |
|---|---|---|
| 커버 제목·부제 | `home.hero` | 1번 슬라이드의 제목·부제 (`\n` 은 줄바꿈) |
| 커버 태그·버튼 | `home.hero_meta` | 태그 칩(1~8개), 버튼 2개의 문구·링크 |
| 커버 슬라이더 | `home.slides` | 슬라이드(1~6장)의 라벨·제목·설명·이미지·링크 |
| 이번 기수 핵심 5 | `home.highlights` | 핵심 문장(1~8개) |
| 2트랙 카드 | `home.cards` | 코스 카드(1~4개): 이름·상태 배지·소개·회차·수강료·산출물·링크 |
| 커리큘럼 표 | `home.timeline` | 회차 표(1~24행): 회차·일정·주제·코스·★ 강조 |
| 손에 남는 것 | `home.outcomes` | 제목·카드(1~6개) |
| 운영 방식 표 | `home.system` | 표 제목·행(1~12개) |
| 강사 소개 | `home.instructor`, `home.metrics` | 이름·소개·신뢰 지표 4칸 (**값을 넣으면 섹션이 나타남**) |
| 수강 안내 | `home.enrollment` | 일정·수강료 표·입금 계좌·안내 문구 |
| FAQ | `home.faq` | 질문·답변(1~20개) (**값을 넣으면 섹션이 나타남**) |
| 탭 제목·설명 | settings `seo` | 브라우저 탭 제목, 검색 설명 |

이렇게 말하세요:

- "메인 첫 화면 제목을 '○○○'로 바꿔줘"
- "히어로 태그 2번째를 '매주 금 20~22시'로 바꿔줘"
- "커버 슬라이드 2번째 설명을 ○○로 바꿔줘"
- "B코스 카드의 상태를 '마감'으로 바꿔줘" (`status`, `tone` 은 `live|open|closed`)
- "커리큘럼 표에 B 4회차(11/13)를 추가해줘"
- "수강료를 A코스 20만원으로 바꿔줘"
- "FAQ에 '다시보기 되나요?' 질문을 추가해줘" (답변 내용을 함께 알려주세요)
- "강사 소개를 추가해줘" (이름·소개를 함께 알려주세요)

규칙:

- **개수는 자유롭게 늘리고 줄일 수 있습니다**(위 표의 범위 안에서). 번호(01, 02…)와 「다음 장 →」 링크는 자동으로 붙습니다.
- 강사·FAQ 구역은 DB 값이 없으면 사이트에 **표시되지 않습니다**. 값을 넣으면 나타나고, 상단 메뉴에도 자동으로 추가됩니다.
- 슬라이드 이미지는 사이트 안의 파일 경로(`images/cover/…`) 또는 `https://` 주소만 가능합니다. 새 이미지 파일은 Claude Code로 사이트에 올려야 합니다.
- 줄바꿈은 가능합니다 ("두 줄로" 라고 말하면 됩니다).
- 수정 시에는 해당 키의 **전체 값**을 다시 보냅니다. 먼저 현재 값을 확인한 뒤 바꿉니다.

> 참고: `home.tracks`, `home.features`, `home.process`, `home.learn` 은 보조 사이트(newirumcompany, GitHub Pages)용 키입니다. irumcompany.co.kr 메인은 위 표의 키만 읽습니다.

대상: 프로그램 9개의 이름, 분류, 가격, 소개, 기간, 운영 형태, 사용 도구, 순서, 공개 여부, 목록 페이지의 그룹 구성.

이렇게 말하세요:

- "프로그램 목록 보여줘"
- "AI 마케팅 실무 가격을 60만 원으로 올려줘"
- "AI 개발 실무 사용 도구에 Gemini를 추가해줘"
- "공기업 사기업 취업특강을 목록에서 숨겨줘" (비공개 처리, 삭제 아님)
- "숨긴 프로그램을 다시 공개해줘"
- "프로그램 그룹을 ○○ / ○○ 로 다시 나눠줘"

규칙:

- 보내지 않은 항목은 그대로 유지됩니다. 가격만 바꾸라고 하면 가격만 바뀝니다.
- 삭제 기능은 없습니다. 숨김으로 대신합니다.
- **새 프로그램을 추가하면 상세 페이지(`html/courses/<slug>.html`)가 없어서 링크가 404가 됩니다.** 새 프로그램은 Claude Code로 상세 페이지와 함께 추가하세요.

- 현재 신청·문의는 0건입니다(운영 전).

### 2-5. 변경 이력과 되돌리기

이렇게 말하세요:

- "최근에 뭘 바꿨는지 보여줘"
- "메인 제목 변경 이력 보여줘"
- "방금 바꾼 문구 되돌려줘"
- "아까 가격 변경 취소해줘"

규칙:

- 콘텐츠·설정·프로그램·그룹의 모든 변경이 이력에 남습니다.
- **수정은 되돌릴 수 있지만**, 최초 생성 기록은 되돌릴 이전 값이 없어 불가합니다.
- 프로그램 그룹은 한 번에 통째로 교체되므로, 되돌릴 때 그룹 단위로 확인이 필요합니다.

## 3. 작업 방식

1. **현재 값 확인**: 바꾸기 전에 현재 값을 먼저 조회합니다.
2. **변경 실행**: 검증을 통과하면 저장합니다.
3. **전·후 비교 보고**: 바뀐 내용을 전과 후로 알려줍니다.
4. **이력 기록**: 자동으로 남습니다. 필요하면 되돌립니다.

팁:

- 중요한 문구는 **"바꾸기 전에 어떻게 바뀔지 먼저 보여줘"** 라고 시키면 확인 후에 적용합니다.
- 여러 군데를 한 번에 시켜도 되지만, 중요한 것은 하나씩 확인하세요.
- 반영 시간: 저장 즉시 DB에 들어가고, 방문자 브라우저 캐시 때문에 **최대 1분** 뒤에 사이트에 보일 수 있습니다.

## 4. 할 수 없는 일 (Claude Code로 처리)

| 하고 싶은 일 | 이유 |
|---|---|
| 색상·글꼴·레이아웃·애니메이션 변경 | DB가 아니라 코드(CSS/HTML) |
| 새 페이지 추가 | 코드 |
| 프로그램 상세 페이지의 커리큘럼·산출물 수정 | 아직 정적 파일 |
| 새 프로그램 추가(상세 페이지 포함) | 상세 페이지 코드가 필요 |
| 새 섹션 추가, 섹션 순서 바꾸기 | 화면 구조는 코드 |
| 새 슬라이드 이미지 파일 추가 | 파일을 사이트에 올리는 작업은 Claude Code |
| OG 미리보기(카카오톡·슬랙 공유 카드) 문구·이미지 | 공유 카드는 로그인 없이 읽는 크롤러가 보므로 코드에 고정 (탭 제목·설명은 `seo` 로 변경 가능) |
| 프로그램·신청·문의 영구 삭제 | 삭제 도구 없음 (숨김·상태 변경만) |
| 스크립트, `javascript:` 링크, 위험한 HTML 입력 | 보안상 자동 거부 |

## 5. 안전장치

- **관리자만**: Google 로그인 후 `admins`에 등록된 계정만 호출할 수 있습니다.
- **본인 권한으로 실행**: 서비스 키를 쓰지 않고 로그인한 관리자의 권한으로 DB를 호출하므로 DB 보안 규칙(RLS)이 그대로 적용됩니다.
- **입력 검증**: 형식이 틀린 값, 20KB 초과 값, 위험한 코드는 거부됩니다.
- **전체 이력**: 모든 변경이 `site_revisions`에 남습니다.
- **승인 화면 보호**: Claude 커넥터 외 앱의 연결 요청은 승인 화면이 열리지 않습니다.

주의:

- 이 DB는 회원 수강신청 시스템과 **Auth를 공유**합니다. Supabase의 Site URL은 바꾸지 마세요.
- 커넥터를 더 이상 쓰지 않으면 Claude 커넥터 설정에서 연결을 해제하세요.

## 6. 도구 대응표 (참고)

| 말하는 내용 | 도구 |
|---|---|
| 현황 보기 | `site_overview` |
| 문구·설정 조회 | `get_content` |
| 문구·설정 수정 | `set_content` |
| 프로그램 목록 | `list_courses` |
| 프로그램 추가·수정 | `upsert_course` |
| 프로그램 그룹 교체 | `set_course_groups` |
| 신청 조회 / 상태 변경 | `list_applications` / `update_application_status` |
| 문의 조회 / 상태 변경 | `list_inquiries` / `update_inquiry_status` |
| 변경 이력 | `list_revisions` |
| 되돌리기 | `rollback` |

수정 가능한 키:

- 콘텐츠(irumcompany.co.kr): `home.hero`, `home.hero_meta`, `home.slides`, `home.highlights`, `home.cards`, `home.timeline`, `home.outcomes`, `home.system`, `home.instructor`, `home.metrics`, `home.enrollment`, `home.faq`
- 콘텐츠(보조 사이트): `home.tracks`, `home.features`, `home.process`
- 설정: `seo`(탭 제목·설명), `nav`·`footer`(보조 사이트)

신청 페이지(강의 목록·옵션·수강료)는 이 MCP가 아니라 `courses`·`course_options` 테이블에서 오며, 현재는 Claude Code(또는 DB 직접 수정)로 바꿉니다.

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 바꿨는데 사이트에 안 보임 | 1분 대기 후 Ctrl+F5. 그래도 안 보이면 해당 키가 `index.html`/`programs.html`에서 읽는 항목인지 확인 |
| "값이 너무 큽니다" | 20KB 초과. 문구를 줄이세요 |
| "href 는 상대경로 또는 http(s) 링크만 허용" | 링크에 `javascript:` 등을 쓴 경우 |
| "슬라이드는 1~6개", "FAQ 는 1~20개" 같은 오류 | 허용 개수 범위를 벗어났습니다 (2-1 표 참고) |
| "image 는 상대경로 또는 https 주소만 허용" | 이미지에 `http://` 등을 쓴 경우 |
| "cards[0].tone 은 live\|open\|closed" | 상태 색 값은 세 가지 중 하나여야 합니다 |
| 강사·FAQ 구역이 안 보임 | 값을 넣지 않으면 의도적으로 숨겨집니다 |
| 도구 호출이 갑자기 실패 | 로그인 만료. 커넥터를 해제 후 다시 연결 |
| 잘못 바꿨음 | "방금 바꾼 거 되돌려줘" |

변경 이력은 관리자 페이지(`html/admin.html`)의 **사이트 편집** 탭에서도 볼 수 있고, 거기서도 되돌릴 수 있습니다.
