# 이룸아카데미 사이트 편집 MCP 사용 매뉴얼

채팅으로 말하듯 시키면 사이트의 문구·프로그램·신청/문의를 바꿀 수 있습니다.
도구 이름을 알 필요가 없고, 아래 "이렇게 말하세요" 예시를 그대로 쓰면 됩니다.

## 1. 시작하기

### 1-1. 연결 정보

| 항목 | 값 |
|---|---|
| 커넥터 URL | `https://tdayexcmksjfryhthyfz.supabase.co/functions/v1/site-mcp` |
| 로그인 | Google 계정 (관리자로 등록된 계정만) |
| 승인 화면 | `https://www.irumcompany.co.kr/html/oauth-consent.html` |

### 1-2. 연결 방법 (최초 1회)

1. Claude 웹(또는 데스크톱) → 설정 → 커넥터 → 커스텀 커넥터 추가
2. 위 커넥터 URL만 입력 (Client ID/Secret 칸은 비워 둠)
3. 열린 승인 화면에서 **Google로 로그인** → 관리자 계정 선택
4. 앱 이름이 `claude-site-editor`인지 확인하고 **승인**

### 1-3. 연결 확인

채팅에서 이렇게 말합니다.

> 사이트 편집 현황 보여줘

콘텐츠 키, 프로그램 수, 미처리 신청·문의 수가 나오면 정상입니다.

### 1-4. 연결이 안 될 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 이메일/비밀번호 입력란이 나옴 | 구버전 화면 또는 캐시 | Ctrl+F5 새로고침 후 새로 연결 |
| "관리자로 등록되지 않은 계정입니다" | 로그인한 Google 계정이 `admins`에 없음 | 등록된 계정으로 다시 로그인 |
| "허용되지 않은 앱입니다" | 승인 요청의 콜백 주소가 Claude 커넥터가 아님 | 직접 연결한 것이 아니면 닫기 |
| "잘못된 요청입니다 (authorization_id 없음)" | 승인 화면을 주소창으로 직접 연 경우 | 커넥터에서 연결을 새로 시작 |
| 연결은 됐는데 도구 호출이 실패 | 로그인 만료 | 커넥터를 해제 후 다시 연결 |

## 2. 할 수 있는 일

### 2-1. 메인 페이지 문구 (irumcompany.co.kr)

메인은 위에서 아래로 아래 구역으로 구성되며, 각 구역이 DB 키 하나에 대응합니다. (2026-10-08 메인 재구성)
**값이 없는 구역은 사이트에 표시되지 않고, 값을 넣으면 나타납니다**(상단 메뉴도 자동 반영).

| 구역 | 키 | 바꿀 수 있는 것 |
|---|---|---|
| 히어로 문구 | `home.hero` | 제목(2줄)·부제(2줄) (`
` 은 줄바꿈) |
| 히어로 버튼 | `home.hero_meta` | 버튼 2개(`cta1`=강의 신청, `cta2`=기관 제안 요청)의 문구·링크 |
| 히어로 배경 사진 | `home.hero_images` | 사진 1~5장(`src`, `alt`) — 6초 간격 크로스페이드. `tone`: `light`(밝은 이미지·어두운 글자) / `dark`(기본, 어두운 사진·흰 글자) |
| 함께한 기관(로고 롤링) | `home.clients` | 기관 최대 30개: `name`, `src`(로고), `href` |
| 출강 사례 | `home.cases` | 카드 최대 12장: `title`, `image`, `tags`(2개), `href` + `more_href`(전체보기) |
| 강의영역 6개 탭 | `home.areas` | 영역 최대 6개: `name`, `desc`, `audience`, `courses`(3개), `output`, `images`(3장) — 비우면 기본 문구 6개 표시 |
| 숫자로 보는 이룸 | `home.metrics` | 4칸 `{n, label}` — `n` 의 숫자 부분이 카운트업됩니다(예: `11년+`) |
| 인사이트 | `home.insights` | 카드 최대 12장: `title`, `tag`, `image`, `href` + `more_href` |
| 강사 소개 | `home.instructor` | 이름·역할·소개(값을 넣으면 섹션 표시) |
| FAQ | `home.faq` | 질문·답변(1~20개)(값을 넣으면 섹션 표시) |
| 하단 CTA | `home.cta` | 제목·본문·버튼 2개(`primary`=개인 수강 신청, `secondary`=기관 제안 요청) |
| 상담 버튼·SNS | settings `footer` | 기존 필드에 `kakao_url`(https), `sns[{label,href}]` 추가 시 FAB·푸터에 반영 |
| 탭 제목·설명 | settings `seo` | 브라우저 탭 제목, 검색 설명 |

모집·진행 중 과정 카드는 이 표가 아니라 아래 **2-1b 과정(기수) 관리**에서 바꿉니다.

이렇게 말하세요:

- "메인 첫 화면 제목을 '○○○'로 바꿔줘"
- "히어로 배경 사진을 images/hero/1.webp … 5.webp 로 설정해줘" (사진 파일은 Claude Code로 사이트에 먼저 올려야 합니다)
  - 밝은 이미지는 "톤은 light 로" 라고 함께 말해 주세요(글자·상단 메뉴가 어두운 색으로 바뀝니다). 현재 배경은 `images/hero/hero-network.webp`(light)입니다.
- "함께한 기관에 ○○대학, ○○공사를 추가해줘" (로고 사용 허가를 확인한 기관만)
- "출강 사례에 '○○ 기관 AI 업무자동화 4일 과정'(태그: 공공기관, 업무자동화)을 추가해줘"
- "강의영역 3번 '바이브코딩' 설명을 ○○로 바꿔줘"
- "숫자 4칸을 11년+ / 50곳+ / 22개교 / 30개+ 로 넣어줘" (사실 확인 후)
- "인사이트에 ax 웹진 기사 링크를 추가해줘"
- "하단 CTA 제목을 ○○로 바꿔줘"
- "상담 버튼을 카카오 채널(https://…)로 연결해줘"
- "FAQ에 '다시보기 되나요?' 질문을 추가해줘" (답변 내용을 함께 알려주세요)

규칙:

- **개수는 위 표의 범위 안에서 자유롭게 늘리고 줄일 수 있습니다.**
- 이미지는 사이트 안의 파일 경로(`images/…`) 또는 `https://` 주소만 가능합니다. 링크는 상대경로 또는 `http(s)` 만 가능합니다. 새 이미지 파일은 Claude Code로 사이트에 올려야 합니다.
- 줄바꿈은 가능합니다 ("두 줄로" 라고 말하면 됩니다).
- 수정 시에는 해당 키의 **전체 값**을 다시 보냅니다. 먼저 현재 값을 확인한 뒤 바꿉니다.
- 예전 키 `home.slides`, `home.highlights`, `home.cards`, `home.timeline`, `home.outcomes`, `home.system`, `home.enrollment`, `home.tracks`, `home.features`, `home.process` 는 **더 이상 메인에서 읽지 않습니다**(DB에는 보관).

> 참고: `home.tracks`, `home.features`, `home.process`, `home.learn` 은 보조 사이트(newirumcompany, GitHub Pages)용 키입니다.

### 2-1b. 과정(기수) 관리 — 여러 과정을 동시에 운영할 때

메인의 **「모집 · 진행 중인 과정」 카드, 과정별 상세 페이지**는 모두 "과정" 한 행(`site_programs`)에서 만들어집니다.
과정을 추가·종료해도 코드를 고칠 필요가 없고, 채팅으로 처리합니다.

| 하고 싶은 일 | 이렇게 말하세요 |
|---|---|
| 현재 과정 목록 | "등록된 과정 목록 보여줘" |
| 새 과정 추가 | "새 과정 ○○를 비공개로 만들어줘. 일정은 ○○, 수강료 ○○원, 대상은 ○○" |
| 공개 | "○○ 과정을 공개해줘" (처음엔 비공개로 만들고 확인 후 공개합니다) |
| (참고) 대표 과정 표시 `featured` | 2026-10-08 메인 재구성 이후 메인 화면에는 쓰이지 않습니다(히어로는 사진 + 카피). 값은 보관됩니다. |
| 순서 바꾸기 | "히어로 순서를 ○○, ○○ 순으로 바꿔줘" |
| 커리큘럼·FAQ 등 일부만 수정 | "○○ 과정 커리큘럼 3회차를 ○○로 바꿔줘" |
| 신청 페이지(옵션·수강료) 만들기 | "○○ 과정에 신청 옵션 '일반 30만원', '회원 24만원'을 만들어줘" |
| 종료 | "○○ 과정을 마감해줘" (히어로·목록에서 내려갑니다. 신청 페이지까지 닫으려면 "신청도 마감") |
| 다른 사이트 강의 소개 | "○○ 사이트의 '○○' 강의를 외부 강의 카드로 추가해줘. 주소는 https://…" |
| 되돌리기 | "방금 바꾼 과정 정보 되돌려줘" |

과정의 핵심 항목: 종류(현장·Zoom / 온라인 / 외부), 상태(모집중·진행중·예정·마감), 제목·부제·한 줄 소개, 기간, 일정·형태·수강료·주관·대상·장소, 홍보 이미지, 신청 방식(우리 신청 페이지 / 외부 사이트).
상세 페이지 구역(`detail`): 개요, 트랙, 배우는 것, 얻는 것, 커리큘럼 표, 운영 방식, 안내 사항, 자료, FAQ, 수강료(외부 과정), **입금 계좌(과정마다 다르게 지정)**.

규칙:

- **과정마다 입금 계좌를 따로 지정**합니다(`payment`: 은행·계좌번호·예금주). 신청 완료 화면에 그 과정의 계좌가 표시됩니다.
- 수강료·옵션은 신청 페이지의 과정(`courses`/`course_options`)이 원본이며, 상세 페이지의 수강료 표는 이를 자동으로 보여줍니다. 옵션 가격을 바꾸면 신청 페이지와 상세 페이지가 함께 바뀝니다.
- 외부 강의는 주소가 `https://` 인 경우만 등록되고, 카드에 "외부 사이트" 표시가 붙으며 새 탭으로 열립니다. 외부 정보는 등록 시점의 내용이므로 정보 확인일(`checked_at`)을 함께 기록하세요.
- 삭제 기능은 없습니다. 끝난 과정은 마감하거나 비공개로 돌립니다.
- 홍보 이미지 파일은 사이트 폴더(`images/programs/<과정주소>/`)에 올려야 하므로 Claude Code로 처리합니다(채팅으로는 경로만 지정).

규칙:

- 보내지 않은 항목은 그대로 유지됩니다. 가격만 바꾸라고 하면 가격만 바뀝니다.

- **새 프로그램을 추가하면 상세 페이지(`html/courses/<slug>.html`)가 없어서 링크가 404가 됩니다.** 새 프로그램은 Claude Code로 상세 페이지와 함께 추가하세요.

이렇게 말하세요:

- "새로 들어온 신청 보여줘"

- 현재 신청·문의는 0건입니다(운영 전).

### 2-5. 변경 이력과 되돌리기

이렇게 말하세요:

- "최근에 뭘 바꿨는지 보여줘"
- "메인 제목 변경 이력 보여줘"
- "방금 바꾼 문구 되돌려줘"
- "아까 가격 변경 취소해줘"

규칙:

- 콘텐츠·설정·프로그램·그룹의 모든 변경이 이력에 남습니다.
- **수정은 되돌릴 수 있지만**, 최초 생성 기록은 되돌릴 이전 값이 없어 불가합니다.
- 프로그램 그룹은 한 번에 통째로 교체되므로, 되돌릴 때 그룹 단위로 확인이 필요합니다.

### 2-6. 현황 확인

> 사이트 편집 현황 보여줘

콘텐츠·설정 키 목록과 최종 수정 시각, 프로그램 수, 미처리 신청·문의 수가 나옵니다.

## 3. 작업 방식

1. **현재 값 확인**: 바꾸기 전에 현재 값을 먼저 조회합니다.
2. **변경 실행**: 검증을 통과하면 저장합니다.
3. **전·후 비교 보고**: 바뀐 내용을 전과 후로 알려줍니다.
4. **이력 기록**: 자동으로 남습니다. 필요하면 되돌립니다.

팁:

- 중요한 문구는 **"바꾸기 전에 어떻게 바뀔지 먼저 보여줘"** 라고 시키면 확인 후에 적용합니다.
- 여러 군데를 한 번에 시켜도 되지만, 중요한 것은 하나씩 확인하세요.
- 반영 시간: 저장 즉시 DB에 들어가고, 방문자 브라우저 캐시 때문에 **최대 1분** 뒤에 사이트에 보일 수 있습니다.

## 4. 할 수 없는 일 (Claude Code로 처리)

| 하고 싶은 일 | 이유 |
|---|---|
| 색상·글꼴·레이아웃·애니메이션 변경 | DB가 아니라 코드(CSS/HTML) |
| 새 페이지 추가 | 코드 |
| 프로그램 상세 페이지의 커리큘럼·산출물 수정 | 아직 정적 파일 |
| 새 프로그램 추가(상세 페이지 포함) | 상세 페이지 코드가 필요 |
| 새 섹션 추가, 섹션 순서 바꾸기 | 화면 구조는 코드 |
| 새 슬라이드·홍보 이미지 파일 추가 | 파일을 사이트에 올리는 작업은 Claude Code |
| OG 미리보기(카카오톡·슬랙 공유 카드) 문구·이미지 | 공유 카드는 로그인 없이 읽는 크롤러가 보므로 코드에 고정 (탭 제목·설명은 `seo` 로 변경 가능) |
| 프로그램·신청·문의 영구 삭제 | 삭제 도구 없음 (숨김·상태 변경만) |
| 스크립트, `javascript:` 링크, 위험한 HTML 입력 | 보안상 자동 거부 |

## 5. 안전장치

- **관리자만**: Google 로그인 후 `admins`에 등록된 계정만 호출할 수 있습니다.
- **본인 권한으로 실행**: 서비스 키를 쓰지 않고 로그인한 관리자의 권한으로 DB를 호출하므로 DB 보안 규칙(RLS)이 그대로 적용됩니다.
- **입력 검증**: 형식이 틀린 값, 20KB 초과 값, 위험한 코드는 거부됩니다.
- **전체 이력**: 모든 변경이 `site_revisions`에 남습니다.
- **승인 화면 보호**: Claude 커넥터 외 앱의 연결 요청은 승인 화면이 열리지 않습니다.

주의:

- 이 DB는 회원 수강신청 시스템과 **Auth를 공유**합니다. Supabase의 Site URL은 바꾸지 마세요.
- 커넥터를 더 이상 쓰지 않으면 Claude 커넥터 설정에서 연결을 해제하세요.

## 7. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 바꿨는데 사이트에 안 보임 | 1분 대기 후 Ctrl+F5. 그래도 안 보이면 해당 키가 `index.html`/`programs.html`에서 읽는 항목인지 확인 |
| "값이 너무 큽니다" | 20KB 초과. 문구를 줄이세요 |
| "href 는 상대경로 또는 http(s) 링크만 허용" | 링크에 `javascript:` 등을 쓴 경우 |
| "슬라이드는 1~6개", "FAQ 는 1~20개" 같은 오류 | 허용 개수 범위를 벗어났습니다 (2-1 표 참고) |
| "image 는 상대경로 또는 https 주소만 허용" | 이미지에 `http://` 등을 쓴 경우 |
| "cards[0].tone 은 live\|open\|closed" | 상태 색 값은 세 가지 중 하나여야 합니다 |
| 강사·FAQ 구역이 안 보임 | 값을 넣지 않으면 의도적으로 숨겨집니다 |
| 도구 호출이 갑자기 실패 | 로그인 만료. 커넥터를 해제 후 다시 연결 |
| 잘못 바꿨음 | "방금 바꾼 거 되돌려줘" |

변경 이력은 관리자 페이지(`html/admin.html`)의 **사이트 편집** 탭에서도 볼 수 있고, 거기서도 되돌릴 수 있습니다.
